<h2><a href="https://leetcode.com/problems/minimum-common-value">2540. Minimum Common Value</a></h2>
<h3>Easy</h3>
<hr>
<p>You are given two integer arrays <code>nums1</code> and <code>nums2</code> sorted in non-decreasing order. Return <em>the smallest integer that appears in both arrays</em>. If there is no common value, return <code>-1</code>.</p>

<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> nums1 = [1,2,3], nums2 = [2,4]
<strong>Output:</strong> 2
</pre>

<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> nums1 = [1,2,3,6], nums2 = [2,3,4,5]
<strong>Output:</strong> 2
</pre>

<p><strong class="example">Example 3:</strong></p>
<pre>
<strong>Input:</strong> nums1 = [1,2,3,4], nums2 = [5,6,7,8]
<strong>Output:</strong> -1
</pre>

<p><strong>Constraints:</strong></p>
<ul>
    <li><code>1 &lt;= nums1.length, nums2.length &lt;= 10<sup>5</sup></code></li>
    <li><code>1 &lt;= nums1[i], nums2[i] &lt;= 10<sup>9</sup></code></li>
</ul>
