<h2><a href="https://leetcode.com/problems/number-of-1-bits">191. Number of 1 Bits</a></h2>
<h3>Easy</h3>
<hr>
<p>Write a function that takes an unsigned integer and returns the number of <code>1</code> bits it has (also known as the Hamming weight).</p>

<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> n = 00000000000000000000000000001011
<strong>Output:</strong> 3
</pre>

<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> n = 00000000000000000000000010000000
<strong>Output:</strong> 1
</pre>

<p><strong>Constraints:</strong></p>
<ul>
    <li>The input is a 32-bit unsigned integer.</li>
</ul>
